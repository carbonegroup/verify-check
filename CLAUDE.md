# Claude Code

`AGENTS.md` est la source canonique des instructions de ce dépôt.

Avant toute modification :
1. Lire `AGENTS.md` et les éventuels `AGENTS.md` du sous-dossier concerné.
2. Inspecter l'état Git, les manifests et les fichiers concernés.
3. Faire un changement limité, exécuter les vérifications pertinentes et relire le diff.
4. Respecter les règles de sécurité, de confidentialité des données élèves et de revue humaine.

Ne suppose pas qu'une compétence, un outil ou une commande est disponible sans le vérifier.
